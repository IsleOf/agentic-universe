## Three concrete v2 additions it implies (each small, each gated, none built)
1. **Gate the gate** — a patch touching `acceptance_gate.py` thresholds, `loop_proposer`
   dimensions, `harness_registry`, or the certificate signer is a *self-design* edit → route
   through `phase5_exec_guard` (token + owner ack), never the ordinary commit path (~15 lines
   in the patch classifier).
2. **Externalise the certificate key** — move it from a repo-local secret to the
   owner-controlled scheduled-task env, so a certificate is only mintable outside the
   evolving code.
3. **Startup manifest check** — the conductor compares `harness_manifest_hash` against the
   last owner-blessed `harness_registry` baseline before its first increment; mismatch halts,
   no self-heal.
