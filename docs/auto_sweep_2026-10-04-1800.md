an aggregate pass rate barely moves (-2..-6pp) while a faulty component's slice craters (-25..-91pp). The

  `by_category(scores)` returns the per-category aggregate.
- `improvement_loop.verify_loop_edit` — now **rejects a proposed loop-harness edit if any task category
  regresses, even when the overall aggregate improves.** The verdict evidence carries `category_regressed`,
  `category_before`, `category_after`.
- New selftest: an edit that lifts `literature` 8→10 while dropping `design` 7→6 (aggregate *up*) is rejected
  as `category_regressed=['design']`.
