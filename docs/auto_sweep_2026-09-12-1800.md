A mechanistic framework: each agent is a single-layer linear-self-attention transformer doing
GD-like in-context updates on a quadratic objective; two agents alternately update from each other under
misaligned fixed objectives. Results in that simplified setting:

- misalignment → a **biased equilibrium** where neither agent reaches its target; residual error is
  **predictable** from the objective gap and the prompt-induced geometry
- an **adversarial regime**: asymmetric convergence — one agent reaches its objective exactly while
  inducing persistent bias in the other
- an adaptive contrast: a helper agent doing a Newton-like turn-based objective update removes the plateau
- trained LSA agents **and black-box GPT-5-mini** runs are consistent with the theory in that setting
