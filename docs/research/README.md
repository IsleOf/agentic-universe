3. **Co-Evolution** — Agent-agent, agent-environment, meta co-evolution
4. **Creativity & Diversity** — Anti-homogenization, ontological creativity, cyber-creativity
5. **Emergence** — Scaffolded emergence taxonomy, institutional formation, communication channels
6. **Developmental Systems** — Staged curricula, self-generated worlds, morphogenesis
7. **Ecological Orchestration** — Resource constraints, stigmergy, persistent artifacts, agent cells
8. **Epistemic Governance** — Claim markets, forecasting, adversarial collaboration, calibrated trust
