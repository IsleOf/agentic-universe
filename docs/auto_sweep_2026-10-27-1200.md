## What was found — and what was excluded
Folded **"Beyond Scaling: Agents Are Heading to the Edge"** (arXiv:2605.18535,
Tian/Cai/Zhao/Lane, 2026-05-18, VERIFIED). Three arguments:

1. **The Prefrontal Turn** — "the main marginal lever of capability has moved from
   pre-training scale to framework-level executive control", and that control must stay
   physically near the environment of action to preserve cognitive alignment.
2. **The Data-Geography Paradox** — the "dark matter" of agentic data (local file
   hierarchies, real-time sensor streams, transient OS states) degrades or loses meaning once
   prepared for cloud transmission, cutting the agent off from ground truth.
3. **The Interaction-Alignment Loop** — the only sustainable source of agentic refinement data
   is the high-fidelity implicit preference signal from real-time *local* interaction.

**It is a position paper.** No benchmarks, no model names, no parameter counts, no
quantitative comparison. Folded at **confidence 0.4** on that basis: convergent *framing* for
the harness-first thesis (which already has empirical support in Harness-Bench and AHE), with
arguments 2 and 3 as its own contribution — both bearing directly on the local-first setup
this project runs on.
