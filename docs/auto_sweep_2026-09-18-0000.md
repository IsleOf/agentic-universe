## The methodological point
The interaction language is a **variable** in every emergence probe, not a constant. A norm / coordination /
deception / trust result measured only in English is a result about English-run agents, and — per Shibboleth —
it may not transfer, and it transfers *differently per model*. Any future probe spec in
`docs/emergence_probe_catalogue.md` should name the interaction language as a controlled factor, and the
cheapest probes (`docs/probe_idle_agent.md`) already carry a model-family arm — a language arm is the same cost.
