## Increment
Run 404's "Next": the "notice the shift" half of the fix. `pheromone.register_health()`.

## What it is
Over the most recent N annotations carrying an `evidence` text / note / message string, the
fraction whose text contains at least one of a tiny closed set of English function words
(`the / a / is / and / ...`). Pure stdlib, **model-free** — a distribution-shift detector, not a
language model.

- Returns `drifting: True` only with **≥ 20 judgeable texts** and an **English fraction < 0.5**.
- **Declines to score** (`n_texts: 0`, `english_fraction: None`, `drifting: False`) when nothing
  carries judgeable text — the declare-your-corpus / run-386 discipline. It doesn't invent a
  health number from no data.
- `drifting` is a signal to **escalate a sample to a human**, never an abort.

## Verified against the run-404 rig
A board of 22 or 45 **coded** annotations (`@x9 kk dx qq vv`) that `g1_evidence` passes as clean
is flagged `drifting`; a plain-English board is not; a 3-annotation blip doesn't trip it.

## What it is not
A keyword monitor with extra steps. It doesn't try to *read* the annotations — it measures
whether the board is still in a register its readers' tools were built for. And an adversary who
keeps sprinkling function words into otherwise-coded text defeats it: **it raises the cost of
covert drift, it doesn't prevent it.**
