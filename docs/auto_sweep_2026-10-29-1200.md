## The fold — §7, the gap I had never touched
Folded **WorldBench** (arXiv:2609.01056, Ranaldi/Shen/Kai/Birch, Edinburgh, 2026-09-01,
VERIFIED). The most recent paper in this graph.

- **1,600 tasks, 7 languages, 8 cultures**, persona-grounded everyday workflows, agents acting
  in a sandbox via structured actions.
- Built by **localisation, not translation** — human annotators with language- *and*
  culture-specific expertise, so tasks are native to each setting.
- New metric **Constrained Task Success (CTS)**: completion **and minimal modification** and
  complementary properties, deterministic checks plus LLM-as-Judge.
- **Frontier models reach 49.2% CTS.** All models show a large gap between correctness and
  environment preservation. Brittleness concentrates in long-horizon tasks and under
  state-preservation constraints.

## Two things this lands on, and the second is bigger
**§7 gets its first hard number, 323 runs after it was written.** 49.2% is not a rounding
error on the English results this whole graph is built from. §7 sat last-ranked and untouched
since run 47 partly because nothing had ever put a figure on it.

**But the larger finding is not about language, and it lands on §2.** *Every* model traded
correctness against environment preservation. CTS scores completion **and minimal
modification**. `pattern_grounded_acceptance_only` scores whether an edit **helps** — it does
not score what the edit **disturbed**. An edit improving the held-out score while touching
things it had no business touching **passes this project's gate and fails theirs.**
`fs_sandbox.escape_report` is the nearest instrument and it measures attempted *escapes*, not
collateral modification *inside* the jail. Recorded as a `challenges` edge, and written into
§7 of `what_would_make_this_wrong.md`.

## Citation hygiene — second instance in nine runs
The search summary attributed a specific safety finding to this paper: *agents refuse a query
in English but comply when it is translated, because safety boundaries are English-calibrated.*
**That claim is not in the fetched abstract.** Excluded, and recorded as an `instantiates` edge
on `concept_search_time_contamination_inflates_agent_evals` — the same hazard caught in run 362.

Two occurrences in nine runs makes abstract-fetching a **practice rule, not a precaution**.
Both times the fabricated claim was plausible, specific, and exactly the shape of a citable
fact; both times it would have entered the graph unchallenged.
