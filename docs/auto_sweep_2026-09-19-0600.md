## Sources folded in

### `concept_epistemic_sybil_collapse` — arXiv:2609.01873 (VERIFIED)
20,000+ LLM-agent calls on synthetic documents. Holding one evidence source fixed and multiplying reports from
1 to 32 agents, **naive posterior coverage collapsed from 0.940 to 0.263**. The extra agents extracting from the
same evidence produce correlated errors, not corroboration. "Collective inference should track evidential
ancestry and dependence, not agent or report multiplicity or similarity."

This is the second quantified hit on the diversity keystone (`principle_diversity_maintenance`). The keystone
defends against shared *priors* (heterogeneous models, decorrelated prompts); it does nothing about shared
*evidence*. "2 diverse ≥ 16 homogeneous" is a generation-diversity claim and does not carry to aggregation.

### `pattern_evidential_ancestry_tracking` — the fix
Dedupe agent reports by evidence root before aggregating: N agents that all read document D count as one
observation of D. A hard requirement on Phase 2 of `docs/self_improving_harness_plan.md` — the experience bank
is shared upstream context for every later run, and a pattern condensed from 12 agents that shared one trace is
a single-source claim with a crowd's authority.

### `emergent_compositional_private_language` — arXiv:2609.01491 GlossoGen (VERIFIED)
Agents under partial-information communication pressure develop languages that are "compositional and
morphologically productive" and "deviate from the LLMs' English prior in ways that render them incomprehensible
to humans." Model-scale asymmetry: **strong models originate a novel language, weak models acquire it from usage
alone** — so one capable agent can seed a private code the rest of a heterogeneous swarm then learns. Framed by
the authors as a safety/monitorability concern.

Direct challenge to the design's transparency bet (§3.4): a logged, everyone-visible broadcast channel is not
transparent if the traffic is in an evolved code. `pattern_five_w_message_instrumentation` is syntactic — it
records that a message passed, not what it meant. Design updated: the adversarial monitor flags *unreadable*
traffic as a signal; the activation probe (internal state, not messages) is the monitoring path that survives
the channel going dark; a language-drift detector on the broadcast log as a cheap early alarm. None tested.
