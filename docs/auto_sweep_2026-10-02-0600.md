## The rig
8 agents with a latent competence per task family, generated with a **cluster
similarity structure** (same-cluster families correlated, cross-cluster
near-independent). Three trust models fit on 9 train families, used to rank agents on
3 held-out families:
- **UNIVERSAL** — one scalar per agent (assumes full transfer)
- **DOMAIN_KEYED** — per-family; a held-out family is a cold start on the global prior
- **SIMILARITY_WEIGHTED** — held-out trust = cluster-weighted average of train-family trust

## Verdict — CONFIRMS
| model | held-out rank corr | authority concentration |
|---|---|---|
| domain_keyed | **−0.00** (chance — cold start) | — |
| universal | +0.49 | **1.00** (one agent crowned everywhere) |
| **similarity_weighted** | **+0.76** | 0.59 |

Trust transfers — **partially, scaled by family similarity** — without granting
universal authority. Strict per-family trust throws away real cross-family signal;
universal trust overclaims *and* concentrates authority on one agent.
