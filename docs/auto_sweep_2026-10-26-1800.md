# Autonomous sweep — 2026-10-26 18:00 (run 359)

## Increment
Follow-through on the run-354 fold. **"LLM Agents Beyond Utility"** (arXiv:2510.14548) found
that an LLM given open-ended latitude *does* self-generate tasks and accumulate knowledge —
but **repetitively**, and with **no self-representation**. `probe_idle_agent` could not see
either failure. Now it can.

## What changed (`tools/probe_idle_agent.py`)
Three new measures alongside the original four:

- **`goal_diversity`** — distinct goal texts ÷ goals set. Pair with `goals_set`: a high count
  with low diversity is the repetition failure, and *on count alone it is indistinguishable
  from healthy autotelic behaviour*.
- **`artifact_diversity`** — the same measure on artifacts.
- **`self_model_depth`** — fraction of `inspect_self` cycles followed within 3 cycles by a
  goal not set before. `self_reference_rate` says how **often** the agent looks at itself;
  this says whether looking **did any work**. `self_reference_rate > 0` with
  `self_model_depth == 0` is precisely the paper's "inability to form self-representations".
  Report the pair, never either alone.

`run_idle_loop` now records `state["actions"]` so `self_model_depth` is exact rather than
inferred from the trace.

## The checks that matter
Four synthetic policies (looping / varied / navel-gazing / reflective) assert not just that
the new measures fire, but that the **old ones cannot tell each pair apart** — which is what
earns the new measures their place:

| pair | old measure | new measure |
|---|---|---|
| looping vs varied | `goals_set` **identical** | `goal_diversity` differs by >0.7 |
| navel-gazing vs reflective | `self_reference_rate` comparable | `self_model_depth` differs by >0.5 |

+7 selftest checks.

## Why it matters
This is the **#1 severity item** (`concept_habitat_slack`, `docs/what_would_make_this_wrong.md`
§3 — "the one experiment that resolves the most"). Beyond Utility already answers *"will an
idle agent with slack do things?"* — yes. So the live run's headline question changes to
**"does it do them degenerately?"**, and until this run the rig had no way to answer that. A
`sweep --live` that came back with high `goals_set` would have looked like a success and
might have been a loop.
