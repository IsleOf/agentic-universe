## What was built
A deterministic coordination substrate (`task_ledger.py` shape: atomic write, `.audit`
log, no model calls). The generative work is the caller's `contribute(node,
neighbourhood)` callback. Three mechanisms:

1. **shared artifact store** — a `direction` string + an append-only list of per-agent
   contributions; **no orchestrator, no message bus**
2. **bounded-neighbourhood read** — an agent about to contribute sees only the last
   `neighbourhood` contributions on its branch + the direction (Kiro ring topology)
3. **adaptive fractal spawn/compress** — expand a node into ≤ `max_children`
   depth-bounded children **only** when the contribution returns
   `unresolved_boundaries`; when every child returns, replace the subtree with a
   one-line summary and shrink the workspace

## Fix
`_maybe_compress` was re-compressing already-resolved subtrees, causing an infinite
oscillation (a parent's compress-pass reset a done child to `compressed`, the child's
own compress-pass reset it to `done`, forever). Now it no-ops on any node that is not
`open` — a resolved subtree is never touched again.
