## What changed
- **`annotate(..., isolated=True)`** — writes a **private working note**. A new
  `isolated` column (int, default 0), with an `ALTER TABLE` migration for DBs
  created before this run.
- **`read(task_ref, *, reader=None)`** — a new `reader` param:
  - `reader=X` → the read includes `X`'s own isolated notes plus every committed
    row; isolated notes by *other* agents are withheld and counted in
    `isolated_withheld`.
  - `reader=None` (a gate, the board) → **every** isolated note is withheld. A
    checkpoint sees only committed findings.
- **`release_isolation(task_ref, *, agent)`** — commits an agent's isolated rows
  to the shared board at a commitment boundary. Author-bounded (an agent releases
  only its own); monotonic (isolated → visible, never back). Returns the count.
- `_live_rows` gained the `reader` param; its 3 callers updated.

This is the ArcticSwarm pattern at the substrate's resolution: agents on one task
gather evidence independently, then commit at a boundary — instead of every
`pheromone.read()` seeing every peer's in-flight annotation immediately (the
real-time-sharing anti-pattern that cost ArcticSwarm 3.8pp).
