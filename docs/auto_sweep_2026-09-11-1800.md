## `principle_structural_edits_gated_outside_the_agents`

All three are an **agent changing the structure it then runs inside**, and all three fail the same way: the agent's own output becomes the thing that validates the change (verifier collapse, routing manipulation, authorization laundering).

**The rule:** a structural edit is accepted only against a source *outside the agents* — a frozen held-out set, a computed check, a source event, a cross-family verifier — never against the trace the editing agent produced.

This is the **one place the emergence-first interior is not ungated**, and it's not a process constraint on reasoning: the agent proposes structural changes freely; only the acceptance signal is external. Same shape as `principle_terminal_gate_only`, applied to self-modification of structure rather than world-affecting acts. `depends_on pattern_deterministic_self_improvement_guardrails` — PROCTOR's five are the concrete instantiation of "a source outside the agents."
