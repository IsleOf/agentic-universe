## The hypothesis
The paper's penalty comes from **private convention interference** — an agent carries conventions
learned with its former partner into the new team. This repo's substrate has **no private
channel**: the board and the ledger hold all coordination state. So a rotation should carry no
**structural** cost.

## Result
Matched pipelines — one with a forced agent rotation at the draft stage, one without — counting
ledger tasks, annotations, handoffs:

```
overhead k=4:  {ledger_tasks: 0.0, annotations: 0.0, handoffs: 0.0}
overhead k=8:  {ledger_tasks: 0.0, annotations: 0.0, handoffs: 0.0}
```

**Exactly zero.** A handoff costs the same regardless of who picks it up, because the
coordination state — the ledger stage, the board annotations, the handoff trace — is *external*,
not in either agent's head. A newcomer reads the same board the incumbent did.

## What it cannot show (in the verdict)
The fake workers make no model calls, so there's no model-level convention to interfere with.
This establishes the **weaker structural half**: if a board swap penalty exists for real agents,
it isn't coming from the substrate's machinery. That's the argument for why externalising
coordination state **might** make rotation cheaper — **not proof that it does**. Whether real
model agents coordinating through a board still pay the convention-interference penalty is a
live-model question.
