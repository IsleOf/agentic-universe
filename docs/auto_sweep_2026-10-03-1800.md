## What it is
An open-source toolkit for studying how failures emerge from **interaction dynamics** rather than individual
model errors. Each experiment is a **topology–environment–protocol–agent–task quintuple** (reproducible,
config-based). Components: flexible communication topologies, swappable interaction protocols,
trajectory-grounded evaluation, extensible registries for **risk detectors** and agent backends.

Four risk categories — **collusion, resource overreach, semantic drift, strategic misreporting** — which map
onto existing graph nodes (`emergent_deception_and_collusion`, `concept_irreversibility_budget`,
`emergent_compositional_private_language` / `concept_compaction_cliff`, `emergent_recognition_execution_gap`).

## Why it matters
This is **independent convergence on what the project built ad hoc**: six `tools/probe_*.py` rigs +
the Phase 0 trace substrate. Trajectory-grounded evaluation, swappable topology/protocol, a detector registry —
the project has all of this, scattered. The quintuple is a cleaner formalisation of the project's
`(scoped task, peer set, constraints)` interface + trace.

**Concrete use:** RiskLab is a candidate real substrate to port the six probe rigs onto as risk detectors for a
non-synthetic multi-agent run — added to `docs/HANDOFF.md` as a Phase 6 integration option.
