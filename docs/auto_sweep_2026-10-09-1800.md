## Finding — the watchdog is already ~70% of the pattern
`ev_hunter_checklist_watchdog.py` already has: a deterministic queue parse (between HTML
markers), state outside the repo, one deterministic pick per tick, `[BLOCKED: …]` skip, a
4-hour stalled-item backoff, and `checklist_worker_recovery.py` does targeted child
cancellation. It is `task_ledger` + `supervisor` in a markdown-queue form — and the
markdown queue is a *feature* (the owner edits `[BLOCKED]` / `[PRIORITY]` markers in
place), so a JSON-ledger swap would be a regression.

## The three real gaps (each ~40 lines inside `run_tick()`)
1. **No per-item attempt budget.** The 4-hour backoff has no ceiling, so the ~39 blocked
   items re-try forever and never leave the "unchecked" count. Add
   `attempts[fingerprint]`; at `>= 3`, rewrite the checkbox to `[!]` / `[EXHAUSTED]` —
   visibly out of the ready set, still auditable, human-cleared (exactly like `[BLOCKED]`).
2. **No active-dispatch deadline.** The watchdog confirms the *paste* landed (45 s) but
   nothing bounds the worker's run — `task-330`'s worker ran an unbounded `find` + a
   `cProfile` against the production paper writer for ~19 minutes. Add
   `dispatch_started_at`; abort via `checklist_worker_recovery.py` past
   `DISPATCH_DEADLINE_SECONDS` (start 900 s). This is the supervisor's abort-over-deadline;
   `agy_command_safety_watchdog.py` handles unsafe *commands*, this handles runaway
   *duration*.
3. **No failure digest.** Keep `recent_failures` (last ~10) and prepend a one-line
   "AVOID: <category>" to the dispatch prompt when a worker last drifted that way.

## The D-state hang itself
Gaps 1–3 stop a hung worker from poisoning the queue but don't fix the root cause — AGY
processes entering WSL `p9_client_rpc` uninterruptible sleep. That's a WSL/9p or
AGY-startup issue (`--noprofile --norc` already removed the profile `manpath` trigger).
`polybot__q_worker_fleet_fix` stands: a further startup fix (native ext4 working dir vs a
`/mnt/c` 9p mount; a pre-warmed pane pool) or is "restart WSL" the accepted boundary? If
the latter — a watchdog check for `>= 2` D-state panes that emits one "manual WSL restart
needed" alert instead of silently stalling.
