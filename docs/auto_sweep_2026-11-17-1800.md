## What changed
- **`SwarmDemo(..., agent_models={agent: {"family": str, "tier": int}})`** — when
  set, `_fresh_validator(task_ref, executor=…)` prefers a validator whose model
  **family differs** from the task's executor **and** whose **tier ≥** the
  executor's, then reputation order within that best-keyed group.
- **`_reviewer_model_report(validator, executor)`** — the G1 / G4 transcript
  entries now carry `same_model_review` / `weaker_reviewer` /
  `reviewer_tier_delta` when `agent_models` is supplied. This is a **seventh
  advisory signal** (design doc §8), same REPORT-not-block posture: same-model
  review over-rejects ~35% of correct answers, a weaker reviewer is negative
  value.

## Result

- An **all-one-family** fleet: `same_model_review` flagged at every gate — and
  still releases (a REPORT, not a block).

The substrate still has no model signal of its own — the caller supplies
`agent_models`, or the rule is inert (backward-compatible: existing callers pass
