## What was built
`LoopSession` — a context manager the loop wraps its work in. Each action emits a Phase 0 event as it happens:
`s.cite(arxiv_id, verified=)` → CLAIM with the arXiv id as evidence root; `s.tool(name, purpose, ok=)` →
TOOL_CALL/RESULT; `s.graph_write(nodes=, edges=)` → ARTIFACT; `s.note()`; `s.commit(sha)`. On exit it closes the
run STEP, validates the trace, and writes `runtime/observations/loop_runs/run-<N>.json` (committed; raw JSONL
gitignored). The loop-harness manifest is stamped into every trace.

`SKILL.md` now has a `RECORD THE RUN` step requiring the wrapper — the traces are the dataset the self-improving
harness reads, not optional bookkeeping.
