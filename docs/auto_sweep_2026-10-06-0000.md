## The paper
Self-evolving agentic code generation as a **constrained learning** problem — hard
formal specifications + soft objectives (task utility).

- **Formally Guarded Generative Models (FGGM):** the planner LLM writes a
  first-order-logic **output contract** for each generative model call; each call
  wraps the model in a **rejection sampler with a verified fallback**, so every
  returned output satisfies the contract for *any* input and *any* parameter setting.
- **Three stages:** Search (synthesise candidate parametric programs with FGGM
  calls) → Verification (prove correctness w.r.t. the hard constraints for **all**
  parameter values, reducing to unconstrained learning) → Learning (GRPO-style
  fine-tuning improves the soft objective while the verifier preserves correctness).
- Dafny / symbolic math / τ²-bench tool use: **zero constraint violations** *and*
  gains over unconstrained + SOTA baselines.
