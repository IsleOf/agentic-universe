introducing a 9th type used by only 8 edges risks breaking assumptions in tooling and downstream docs that
enumerate the current vocabulary, for a 7% cleanup. A documented dual convention is the lower-risk fix. If a
future run does a full schema pass, retyping these 8 to `mitigates` is the right call.
