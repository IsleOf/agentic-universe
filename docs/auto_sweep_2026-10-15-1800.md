## What it shows
An open-source long-horizon harness with four load-bearing pieces:
1. **Persistent IPython REPL** following the Recursive Language Model (RLM) abstraction —
   programmatic context processing + test-time compute.
2. **Continual Harness** — histories, memories, skills, prompts, subagent specs persist
   across trajectories.
3. **Recursive subagents** coordinating via direct agent-to-agent communication.
4. **Agents View** — humans inspect and manage daemon-backed sessions.

Thesis: standardise execution / recovery / verification / resource accounting in the
harness, leave **strategy** to the model — "a low-friction, expressive membrane [that]
prevents harness failures from becoming model failures and pushes measurement toward the
model's true maximal underlying capability."

Results: ARC-AGI-3 RHAE Best@1 **30% -> 95.5%**; matches/exceeds native and popular harnesses
on long-context coding, GPU-kernel generation, emulator construction, nanoGPT speedruns;
Factorio shows continuous advancement + parallelised execution.
