## The finding
- **The inter-agent communication graph is the detection substrate.** A GNN
  (edge-featured graph attention) trained over inter-agent connections
  **localises** dangerous agents and intervenes **structurally** — topology as a
  containment lever, not reactive per-message blocking.
- **Federated (FGLGuard):** operators can't pool private prompts / tool outputs /
  proprietary workflows, so each trains a **local** detector on its own labelled
  episode graphs and shares **only model updates**.
- **Results:** federated FGLGuard *exceeds* centralised in-domain across three
  benchmarks without pooling; a single federated guard across **four**
  different-domain operators is within **0.03 AUROC** of full centralisation; live
  deployment cut AgentDojo attack-success by **43%** at **zero API overhead**.
- **Centralised transfer learning collapsed:** AUROC 0.51 → 0.70 only after
  in-domain retraining — a detector trained on one operator's attacks does not
  transfer.

## Why it lands here
- The swarm substrate is **flat**: every agent reads one shared pheromone board,
  so there is **no connection graph** to learn a detector over and **no
  structural containment lever**. `probe_subagent_coordination`'s same-parent-ID
  filter is a hand-coded topology constraint; this is its learned generalisation.
  `cohort_monitor` sums per-worker signals but is not graph-structured.
- **Cheap first step:** the Phase 0 trace has `sender` / `receiver` on every
  MESSAGE — a per-run inter-agent graph is already derivable and is a monitoring
  surface the loop does not use.
- **Federation answers the Civilization framework's silo problem** (run 454):
  independent civilizations that cannot pool episodes *can* pool a detector's
  parameters. And "centralised transfer collapsed" is a hard version of "a
  detector's first output is a claim about the detector."

Small-model note: a GNN detector is small and cheap (zero API overhead reported) —
the topology of a small-local-model fleet is exactly what a resource-constrained
operator can afford to monitor.
