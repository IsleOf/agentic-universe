## Key Findings

### Compensation Benchmarks (2026)
- **US Senior Roles**: $200K–$430K base (Anthropic $405K–$485K, OpenAI $230K–$385K, NVIDIA $272K–$431K)
- **Europe**: €60K–€180K typical, €500K outliers (EWOR equity-heavy)
- **Asia**: $30K–$120K typical

### Role Tiers
1. **Core Harness Engineering** - Execution loop, tool calling, context/memory
2. **Agentic Orchestration** - Multi-agent coordination, workflow orchestration
3. **Self-Improving Agents** - Reflection, critique, meta-agent frameworks
4. **Evaluation & Rig Engineering** - Golden datasets, CI gates, regression suites
5. **Forward Deployed** - Client-facing deployment, production instrumentation
6. **Research + Applied** - Novel architectures, production deployment

### Technical Patterns
- **Tiered Orchestration**: Tier 1 routers, Tier 2 specialists, Tier 3 utilities
- **Self-Improving Loops**: Reflection, critique, self-debugging as table stakes
- **Evaluation in CI**: Automated gates block releases on regressions
- **Harness as Discipline**: Dedicated teams separate from model training

## Methodology

- **Search Period**: August 1 – September 6, 2026 (6 weeks)
- **Sources**: LinkedIn, Greenhouse, Lever, Wellfound, FrontierRoles, BuiltIn, Monster, Dice, and 20+ other job boards
- **Inclusion**: Explicit agentic/orchestration/harness/self-improving mentions
- **Total Roles**: 100+ high-signal postings analyzed, 1,365+ aggregate on frontierroles.com
