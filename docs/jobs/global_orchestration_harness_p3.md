## Company-Specific Deep Dives

### OpenAI: Codex Core Agents

**Role**: AI Systems Engineer, Codex Agents  
**Compensation**: $230K–$385K  
**Team**: Codex Core Agents — "Builds the agent harness that turns model capability into real-world action".

**Key Responsibilities**:
- Design and build core agent harness and execution loop for Codex.
- Interpret model outputs, use tools, execute code, complete long-horizon tasks safely.
- Run experiments and ablations across model + system prompt + harness stack.
- Build frameworks for assessing production agent performance.
- Turn messy failures into durable improvements.

**Signal**: OpenAI treats harness engineering as **core infrastructure** — not application logic. Compensation is top-of-market ($230K–$385K).

### Anthropic: Claude Managed Agents

**Role**: Staff+ Software Engineer, Claude Managed Agents  
**Compensation**: $405K–$485K  
**Team**: Agentic Systems within Platform organization.

**Key Responsibilities**:
- Build Claude Managed Agents: hosted platform for building, running, scaling production agents.
- Pair Anthropic-built agent harness with production infrastructure (sessions, environments, tools, memory, permissions).
- Design composable APIs stable across model/harness evolution.
- Scale platform: durable session/event storage, sandbox orchestration, streaming, scheduling, multi-tenant isolation.
- Build eval infrastructure measuring harness quality against research baselines and real customer workloads.

**Signal**: Anthropic's compensation ($405K–$485K) is **highest verified** for agentic platform work. Focus on API stability and multi-tenant isolation indicates enterprise-grade ambitions.

**Signal**: NVIDIA is investing **across the stack** — from safety/security harness to open-source tooling to consumer self-evolving agents. Compensation spans $152K–$431K, indicating broad hiring across levels.

### Google DeepMind: Meta-Agent Framework

**Role**: Software Engineer, Science and Strategic Initiatives  
**Compensation**: $174K–$252K + 15% bonus + equity.

**Key Responsibilities**:
- Build self-improving meta-agent framework to diagnose failure modes.
- Generalize learnings across customer engagements.
- Continuously improve agent quality at scale.
- Design/build/operate scaffolding and meta-agent framework across science, cybersecurity, and coding agents.

**Signal**: DeepMind is applying meta-agent frameworks to **production customer engagements** — not just research. Focus on failure diagnosis and generalization indicates mature deployment experience.

### Bosch Group: Self-Improving Industrial Agents

**Role**: AI Research Engineer – Agentic AI  
**Compensation**: $165K–$180K + bonus + LTIP.

**Key Responsibilities**:
- Design/build/evaluate agentic AI systems for complex long-horizon tasks.
- Develop robust agent harnesses and evaluation frameworks.
- Implement **self-improving agent loops** using reflection, critique, self-debugging.
- Architect agent memory systems (short-term/long-term, RAG, summarization, compression, forgetting).
- Enable deployment on constrained/edge environments.

**Signal**: Bosch (industrial conglomerate, €70B+ revenue) is building **self-improving agents for edge deployment** — indicating enterprise readiness beyond tech companies.

## Methodology

**Search Strategy**:
- Queried job boards: LinkedIn, Greenhouse, Lever, Wellfound, FrontierRoles, BuiltIn, Monster, Dice, EuroToptech, Remocate, NextLevelJobs, SimplifyJobs, Haystack, Agents.one, Qarera, BeBee, WorkingNomads, Technyc, H1B-Connect, ZipRecruiter, Magnet.me, JobLeads, StartMunich, SemiWiki, AgenticAcademy, SmartRecruiters, AnitaB, DevJobs, EU-Recruit, Talent.Emcap, Job-Boards.eu, LaborX, ToolHunt, BestXBuilds.
- Search terms: "agent harness", "agentic orchestration", "multi-agent", "self-improving agent", "self-evolving agent", "agent infrastructure", "agent platform", "LLM orchestration", "autonomous agent".
- Date range: August 1 – September 6, 2026 (6 weeks).
- Geography: Worldwide (US, Europe, Asia Pacific, Remote).

**Inclusion Criteria**:
- Explicit mention of agent harness, orchestration, multi-agent systems, or self-improving agents.
- Posted within last 6 weeks (August–September 2026).
- Full-time roles (excluded internships unless explicitly agentic).
- Technical roles (excluded pure sales/marketing unless agentic platform-focused).

**Exclusion Criteria**:
- Generic "AI Engineer" roles without agentic/orchestration specifics.
- Research-only roles without production deployment.
- Contract/freelance gigs (unless high-signal like Sitreps LLC).

**Limitations**:
- Some roles may have been missed due to paywalls (LinkedIn Premium, Greenhouse private postings).
- Compensation data is incomplete for many non-US roles (converted to USD estimates where possible).
- Some companies (e.g., xAI, DeepSeek) have limited public job postings — relied on earlier research for those.

## Implications for Agentic Universe

### 1. Harness Engineering is a Core Discipline

**Evidence**: 15+ dedicated "Harness Engineer" roles across OpenAI, NVIDIA, ImagineArt, LM Studio, FICO, Travelers.

**Recommendation**: Agentic Universe should treat harness engineering as a **first-class module** with:
- Clear interfaces for execution loop, tool calling, context/memory management.
- Evaluation hooks for CI integration.
- Sandboxed execution primitives (Docker, VMs, subprocesses).

### 2. Self-Improving Loops are Table Stakes

**Evidence**: 40%+ of roles explicitly mention reflection, critique, self-debugging, or meta-agent frameworks.

**Recommendation**: Agentic Universe should include:
- Built-in reflection/critique primitives.
- Meta-agent framework for failure diagnosis and generalization.
- Evaluation pipelines that feed into improvement loops.

### 3. Evaluation Must be Integrated into CI/CD

**Evidence**: Phizenix, SonarSource, 10x Labs all mention CI gates, regression suites, golden datasets.

**Recommendation**: Agentic Universe should provide:
- Golden dataset management.
- Automated scorers (faithfulness, grounding, task success).
- CI integration (block releases on regressions).

### 4. Multi-Agent Orchestration is Converging on Tiered Architecture

**Evidence**: Accenture, Light & Wonder, Salesforce all use Tier 1 routers, Tier 2 specialists, Tier 3 utilities.

**Recommendation**: Agentic Universe should adopt:
- Tiered orchestration as default pattern.
- LangGraph-style state machines for workflow orchestration.
- Human-in-the-loop handoff primitives.

### 5. Forward Deployed Engineering is Critical for Enterprise

**Evidence**: Salesforce, Redapt, Sitreps LLC all hire FDEs for client deployments.

**Recommendation**: Agentic Universe should include:
- Deployment tooling (config management, environment provisioning).
- Observability integration (tracing, logging, metrics).
- Workflow mapping and knowledge encoding primitives.

### 6. Compensation Signals Strategic Priority

**Evidence**: Anthropic ($405K–$485K), OpenAI ($230K–$385K), NVIDIA ($272K–$431K) are paying top-of-market for agentic work.

**Recommendation**: Agentic Universe should prioritize:
- Harness engineering and self-improving loops (highest compensation).
- Evaluation infrastructure (critical for production reliability).
- Forward deployed tooling (enterprise adoption bottleneck).
