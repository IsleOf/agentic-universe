## The argument
- `concept_rest_react_founds_the_trajectory_retrain_loop` (arXiv:2312.10003, folded run 122): the earliest
  published multi-iteration self-improvement result gets its gains in **two** iterations, then saturates.
- **A gate only rejects regressions — it does not require progress.** So if the middle loop's returns decay
  the same way, the loop keeps running, keeps passing its grounded-acceptance gate, and quietly stops
  producing real improvement.
- Same observable signature as the model-native-orchestration failure ("improvements stopped landing"),
  different cause — so the two are easy to confuse when diagnosing.
- `concept_recursive_meta_skill_evolution` is the proposed answer (evolve the improvement procedure when
  the object loop plateaus), but *that meta-level search reliably re-opens a plateaued loop* is a
  hypothesis, not a result.
- **Cheap tell:** track the accept-rate and held-out-score trend of the middle loop over a run window; a
  long run of gate-passing edits that don't move the held-out score is the plateau.
