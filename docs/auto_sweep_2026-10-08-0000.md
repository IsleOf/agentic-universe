## The paper
Membership inference attacks (MIAs) — does a given record belong to a system's private
data — are the standard privacy-leakage measure, but prior work targeted training corpora
and retrieval databases, **not agent memory**, which holds sensitive user-agent
interactions, retrieved facts, and user preferences.

**MRMMIA** (Multi-Recall Memory MIA) is a unified attack using multiple recall probes to
the agent to extract the membership signal across black-box, gray-box, and white-box
settings. It consistently beats baselines and gives an initial evaluation framework for
membership leakage in chat-agent memory. Companion: Interrogation Attack (`2502.00306`)
does the same for RAG datastores with 30 natural-text queries, stealthily.
