## What was built
A deterministic module (the shape of `task_ledger.py`: pure stdlib, atomic write,
`.audit` log, no model calls) with three primitives:

1. **claim ledger** — versioned falsifiable propositions (statement / domain /
   confidence / horizon / evidence / disconfirmers / status)
2. **forecast ledger** — predictions made *before* the action, Brier-scored on resolve
3. **conditional trust** — `trust(agent, domain) = 1 − mean Brier` in that domain;
   domain-keyed; cold start returns **`None`**, never a global scalar

**Promotion rule:** ≥4 resolved forecasts from ≥2 agents · aggregate Brier < 0.18 ·
`replicated` · `survived_counterexample`. The last two are set by an external process
(they need a `call_model`) — recorded as required-evidence flags.

Every design choice traces to a rig: the forecast ledger to `probe_epistemic_market`
(286), the cold-start-`None` to `probe_trust_transfer` (290), the unbiased-score
discipline to `probe_dissent_vs_reflection` (291).
