## The caveat, stated loudly rather than buried
γ_cal is a calibration coefficient in that paper's aggregator; `rho` here is a mixture weight in
my simulation. **They are different parameterisations and the mapping is not the identity.** The
plug-in is illustrative, not a calibration. What survives is the **order of magnitude** — the
real figure is far nearer coupled than independent — and that is all the conclusion rests on.
Written into `RHO_EMPIRICAL`'s comment where a caller will hit it.

## The mitigation that does work
Also from 2609.01873, and it answers run 382's original question:

- More agents on **one evidence root** is worthless — coverage collapses **0.940 → 0.263** as
  reports go 1 → 32.
- More **evidence roots** fixes it — 1 → 16 closes the gap entirely.
- A **correlated-extraction aggregator restores calibration.**

So the cure for run 383's calibration failure was never more extractors. It's **modelling the
correlation** and **multiplying evidence roots, not agents**.

## The convergence worth naming
**arXiv:2609.03422** (Tieman & Markou, 2026-09-03) reaches the same negative result by a
different route: generative-process diversity (NCD between raw outputs, residualised) predicts
correlated failure across 38 models where **semantic similarity does not**. Meanwhile 01873
shows report-space **deduplication** moves 1.425 with representation similarity but only
**0.040** with a fourfold change in true ancestry.

Two papers, two methods, one conclusion: **surface similarity is the wrong instrument for
independence.** The obvious way to check whether your two extractors differ — compare their
outputs — measures almost nothing.

And 03422's population is **38 genuinely different models**, still strongly correlated. Run 383
worried about two prompts on one model; the harder finding is that *different models* aren't
enough either.

## What I did not claim
03422's effect size is **−0.216** [−0.309, −0.122]. Consistent in sign across all ten
benchmarks, but weak-to-moderate. It supports "more process diversity → less correlated
failure." It does **not** license certifying a pair independent. You cannot measure your way to
ρ=0 — and run 383 already showed ρ=0 wasn't sufficient for calibration anyway, which makes the
keep-a-differently-shaped-channel corollary **stronger**, not weaker.
