## Found

**`concept_graded_challenge` refined** (→ `partially_validated`). **SPADE** (`arXiv:2608.19197`, VERIFIED): an environment designer that optimises a **regret signal** — the gap between reward *with* privileged hints and *without* — learns to target the edge of the agent's capability while keeping tasks feasible. **+5.3 average over fixed-environment baselines across 8 held-out benchmarks, +13.9 on ACEBench-Agent.** Plus the ACE lens (`2608.27260`): complexity places learning mass relative to learner capability, so difficulty scales with agent evolution.

**`pattern_regret_as_difficulty_signal`** — the measurement the graded-challenge feeder needed. The graph said "present work slightly beyond the current reliable edge" with no way to *locate* the edge. The regret gap is it: run the task with and without hints, take the difference, a large gap means the agent could do it with help but not alone.

**Caveat, recorded as a `challenges` edge:** SPADE's environment designer and reasoning agent are the *same model*. The cross-family-observer rule (run 13) warns a same-model task designer may target tasks that flatter the agent's style. Separate the designer, or verify the regret signal survives separation.

Enriched `emergent_evaluator_mode_collapse` with AgentJudgeBench (`2608.26623`): **judge alignment degrades monotonically with task difficulty, 1.5× faster without ground truth** — the evaluator is least reliable exactly where a graded-challenge feeder pushes the agent.
