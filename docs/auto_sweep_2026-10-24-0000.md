## What it shows
- **ARG-Designer** reframes multi-agent system design as **conditional autoregressive graph
  generation**: conditioned on a natural-language task query, one model sequentially decides
  the agent count, picks each role from an extensible pool, and lays the communication links
  — composition *and* structure designed jointly, from scratch. SOTA on six benchmarks, much
  better token efficiency than fixed / search-based topologies.
- **RGA-Designer** adds an RLHF-style reward model scoring **task correctness AND structural
  compactness** jointly → a further **20.5% token reduction** at equal accuracy.

## Why it matters for this project
- **`pattern_causal_edge_pruning`** — `instantiates`: the compactness reward is edge pruning

- **`approach_emergence_first`** — `challenges`: another "trained harness component beats

- **`concept_agent_shaped_topology_is_agent_corruptible`** — `refines`: a query-conditioned,

- **`concept_multi_agent_helps_when_subtasks_are_verifiable…`** — `informs`: an automatic
