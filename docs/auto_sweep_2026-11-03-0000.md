## What it is
One SQLite table. Any agent calls `annotate(task_ref, kind, utility, confidence, agent=...,
half_life_s=..., ttl_s=...)` — the only mutation, monotonic (append + an optional `supersedes`
pointer so an agent revises its own opinion without an in-place edit). Any agent calls
`read(task_ref)` — no lock, no turn, no permission check. `reap()` is the one privileged
operation and it only garbage-collects expired rows.

## The three things it gets right that Strands / SwarmSys / Ruflo do not

**1. Decay is an explicit clock.**
`effective_utility = utility · confidence · 0.5^(age / half_life_s)`; the row is invisible to
`read()` and reap-eligible once `age > ttl_s` (default 6 half-lives). SwarmSys leaves evaporation
implicit ("other profiles evolve") — that only works when the population churns; a 2–15 agent
fleet can sit idle.

**2. The aggregate threshold scales with the contributor count.**
`read()` returns `signal_raw` (the honest confidence-weighted decayed **sum**, grows with `k`),
`signal` (that clipped to [−1,1] for ranking), and

```
suggested_threshold = k·benign_mean + 3·benign_sd·√(k·design_effect)
```

`actionable` compares `|signal_raw|` to that, never to a bare constant. This is the run-385
defect (`concept_an_absolute_threshold_on_a_pool_sized_sum...`) **applied to a new component at
birth** rather than after it aborted on benign noise. A `range(2, 16)` sweep is in the selftest,
so `param_invariance_audit` does **not** flag it — the first component built after run 387 to
pass that audit by construction.

**3. Correlation widens the null, it does not deflate the signal.**
`design_effect = 1 + (k−1)·ρ`, ρ defaulting to 0.7 (arXiv:2609.01873, shared base model). This
inflates `noise_band` and `suggested_threshold`, but `signal_raw` is the undeflated sum — the
run-386 lesson that k agents doing *different* things are distinct observations, not replicates.

## One design call worth recording
**Stigmergy bootstraps: one strong, confident marker IS actionable.** That is how a trail starts
— one ant finds food, lays a trail, others follow. Requiring a 2-agent quorum before *anything*
is actionable would break the bootstrap. "Actionable" here means *worth an agent's attention*,
not *execute an irreversible action* — that is gated separately (the quorum gates and the
autonomy ladder in the design doc). A single *weak, low-confidence* marker sits below the k=1
noise floor and is not actionable.
