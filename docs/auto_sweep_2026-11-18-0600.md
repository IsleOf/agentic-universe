## The finding
An LLM coding agent implemented a multi-component data retrieval system (storage,
schema, entity resolution, filtering). Five distinct defects, catalogued by
(constraint violated, detection method):

- The defects were **architectural** — schema design, async orchestration,
  configuration correctness — not the syntactic bugs a linter or unit test
  catches.
- **One defect: a claimed performance fix that was never re-measured on the
  regression that motivated it.** The agent asserted an improvement it did not
  verify.

**Two evaluation-rigor findings:**
1. **Component-isolated tests don't exercise the integration** where the defects
   live.
2. **Substituting gold evidence labels for the agent's actual pipeline output
   "prevented real-world validation"** — the benchmark passed while the pipeline
   was broken.

Result (HotpotQA, 2,994-paragraph corpus): filtered retrieval optimal by
budget-3; unfiltered 69% at budget-10 (p < 0.0001) — a real architectural choice
with a large measured effect.

## Why it lands here
Concrete real-world instances of failure modes the project has theorised:
- **"A claimed fix never re-measured"** *is* the ClaimReceipt sufficiency failure
  (run 441) and the tampering-flag "claims a gain with no mechanism" (run 190) —
  and it happened in a *non*-self-improving agent, so the failure is just how
  agents report their own work.
- `sweep_audit` (run 442) checks that a sweep's Next commitments were addressed
  and headlines are backed — but **not** that a claimed FIX was re-verified
  against the regression it fixed. A `refix_check` is the sharper version.
- `selftest_all` is mostly **component** selftests; `swarm_demo` is the one
  end-to-end test — and this paper says end-to-end is where architectural defects
  hide.
- `swarm_demo`'s `_fake_worker` is a **gold substitute**; its selftests validate
  the substrate *mechanics*, not real agent output (acknowledged in the design
  doc).

Limits: single author, N = 1 system, one domain — the direction is the finding,
not a distribution.
