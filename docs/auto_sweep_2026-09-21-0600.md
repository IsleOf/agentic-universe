## Findings wired into the schema
- **`pattern_five_w_message_instrumentation`** — MESSAGE events require all six W's (sender, receiver,
  content_class, timestamp, declared_purpose *at the call site*, channel). A message without a declared purpose
  does not validate.
- **`concept_emergence_layer_model`** — every event carries `layer ∈ {llm, harness, swarm}`. The attribution
  rule from the probe catalogue ("a swarm result one agent in a loop reproduces was never a swarm result") is
  now enforceable, not just stated.
- **`concept_interaction_language_shifts_emergence`** (run 47) — every event carries `language`. English-only
  results are distinguishable from cross-lingual ones at the data level.
- **`pattern_evidential_ancestry_tracking`** (run 52) — CLAIM events carry a required non-empty `evidence_roots`
  list. `concept_epistemic_sybil_collapse` is measurable: dedupe claims by evidence root, not agent count.
- **operating rule 9** — `scrub()` redacts token shapes, key/secret assignments, AWS keys, PEM keys, and emails
  before any write. Selftest asserts a planted secret does not reach disk.

## The gate
Plan's Phase 0 gate: "topology analysis must recover roles in a control condition where roles were explicitly
assigned." `tools/topology_recover.py selftest` synthesises a 24-event control trace — planner, two workers, a
verifier, a **router** (all verifier↔worker traffic relayed through it), an **isolate** observer — and runs
deterministic rule-based recovery:

```
role recovery accuracy: 1.00  (threshold 0.80)
GATE GREEN
```

`python tools/phase0_selftest.py` → `PHASE 0: GREEN`, exit 0.

Recovery took one iteration to fix: the first version misread the planner as a router (a planner is a *directive*
hub, a router is a *relay* hub) and the router as a verifier (it relays critiques). Fixed by checking
STEP-opening and directive fan-out before betweenness, and requiring a router's in/out traffic to be balanced and
class-matched with zero originated work.
