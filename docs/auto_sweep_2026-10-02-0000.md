## The rig
Sweeps the challenge rate `r` (fraction of decisions a red team formally challenges).
Per decision: a latent defect with prob 0.15; a challenge catches it with prob 0.85 at
a throughput cost; above a **`PARALYSIS_KNEE`** (r ≈ 0.35) the system starts
re-litigating un-challenged decisions too, so throughput decays super-linearly. Net
value = throughput·value − shipped_defects·8.

## Verdict — CONFIRMS
| r | net value |
|---|---|
| 0.0 | **−39** (defects ship) |
| 0.3 | 0 |
| **0.5** | **+17** (optimum) |
| 0.65 | 0 |
| 0.8 | −50 |
| 1.0 | **−37** (throughput → 0) |

Net value is a clear **inverted-U** — an interior optimum with both endpoints >20
below it. Under-challenging ships defects; over-challenging (past the knee) freezes the
system. A concrete instance of `concept_environmental_pressure_has_an_inverted_u`.
