## The rig
Three arms — N agents on one shared source / N on independent sources / shared-with-ancestry-dedup — swept
N in {1,2,4,8,16,32}, 400 trials each. `agent_read(source)` = TRUE + a per-source systematic bias (shared by
every reader of that source) + independent read noise. Measure: how often the naive 95% CI of the aggregate
actually covers ground truth. Each read is a Phase 0 CLAIM with its evidence_root.

## Dry-run result (coverage, nominal ~0.95)
| arm | N=1 | N=8 | N=32 |
| --- | --- | --- | --- |
| shared | 1.00 | 0.15 | **0.095** |
| independent | 1.00 | 0.93 | **0.94** |
| dedup | 1.00 | 1.00 | **1.00** |

Reproduces arXiv:2609.01873's direction: adding agents to one source collapses coverage; independent sources
hold; deduplicating by evidence root recovers fully. (The sim's collapse is steeper than the paper's 0.26 —
strong bias parameters; the mechanism is the point.)
