## The question
`2609.03035` (run 49) settled the eval-awareness arm of `pattern_activation_probe_monitoring`. Open: does a
probe **trained on collusion you can label** (agents told to coordinate) generalise to **collusion you can't**
(agents that drifted into it)?

## The rig
A linear probe (hand-rolled logistic, no numpy) is fit on `assigned collusion vs benign` — where assigned is a
strong stereotyped feature shift — then tested on `emergent collusion vs benign`, where emergent is a weaker,
differently-shaped shift it never trained on. A control trains on both. Stub: `sample_signal` (swap for real
activation vectors).

## Dry-run result
| quantity | value |
| --- | --- |
| AUC in-distribution | **1.00** |
| AUC on emergent collusion (untrained) | **0.72** |
| generalisation gap | **0.28** |
| AUC on emergent if trained on both | 0.93 |

**A probe trained only on labellable collusion is a detector for that scenario, not the general observation
channel the two-part gate needs** — and for genuinely emergent coordination the training set can't be collected
in advance.
