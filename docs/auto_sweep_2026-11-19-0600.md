## The experiment
Each honest agent varies (rng): how much of the cheater cohort it encounters
(1–2) and how firm its own *correct* negative assessment is. The **real
`Pheromone`** supplies the board signal and the `suggested_threshold`; a
reader-side `_PRIMACY = 1.35` multiplier (a post-read model, like `_veto_weighted`
— *not* a module property) weights whichever view was committed **first**:

- **unsealed** — the board was seen first → `board_positive * _PRIMACY + own_view`
- **sealed** — own view committed first (`annotate(isolated=True)`) →
  `board_positive + own_view * _PRIMACY`

## Result
| condition | captured (steered to the exploit) |
|---|---|
| reads the contaminated board **first** | **~72%** |
| **seals** its own read, then reads | **~10%** |

The paper's field number is **54.2% vs 31.6%** (a ~42% relative drop). This sim
shows a **larger** effect because the modelled board has no honest counter-signal
and the temporal weight is applied cleanly — **read the direction and "sealing
roughly halves-or-more the capture", not the magnitude.**

`pheromone.annotate(isolated=True)` + `release_isolation` (run 437) **is** the
seal: the substrate already has the mechanism; this measures that *using it before
cross-reading* matters.
