A framework for multi-turn LLM research-agent creativity on ML engineering tasks (10 MLE-Bench tasks,
agents AIDE / AIRA-Dojo), three dimensions:

- **P-Creativity** — novel relative to the agent's *own* prior solutions within a run
- **H-Creativity** — novel relative to the *human* solution corpus
- **Usefulness** — task performance

An LLM-as-Judge pipeline verified against human creativity judgments. Findings:

1. **all agents' P-Creativity declines** as a run shifts exploration → exploitation
2. **LLMs are more H-Creative than medal-winning humans, yet lower performance** — novel, not as useful

Bearing on the project: the project **is** a multi-turn LLM research agent. Finding (1) grounds the
IDLE-STATE RULE / `plateau_watch` at a **within-run** grain — not just "the last 3 runs were doc-only" but
"inside one run, an agent that keeps going repeats itself"; it's ASPIRE's "continued search erases gains"
as a creativity curve. Finding (2) is the **novelty/usefulness gap**: the held-out set scores usefulness,
**nothing scores novelty**, so a novel-but-useless run still passes the gate.

Companion (same dossier section): the **four-role team-formation taxonomy** (arXiv:2601.13865) — Initiator
/ Generator / Evaluator / Refiner — which the project maps as Initiator = the human's standing goal,
Generator + Refiner = the loop, Evaluator = the frozen held-out set.
