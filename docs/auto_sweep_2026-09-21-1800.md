## What was built
A `Registry` over `runtime/harness/<kind>/<name>` for the five component kinds the plan names (prompt, tool,
context, hook, topology). Each component is a body file plus a `history.json` version chain. **Every version
retains its body**, so `revert()` is exact by construction — the purpose-built recovery machinery
`pattern_recoverability_constrained_evolution` requires (conventional rollback recovered 0/197 in EvoUndo).

- `set()` no-ops on an unchanged body.
- `revert()` is recorded as a new append-only version pointing at the restored hash (`author: "revert"`) — you
  can see a revert happened and to what.
- `manifest()` hashes the whole harness state; `Recorder(harness_manifest=...)` (added to
  `tools/trace_substrate.py`) stamps it as the run's first event. **A result is now attributable to exact
  component versions** — the precondition for the Phase 3 rule "promote iff prediction held *and* blast radius
  did not widen."

Selftest GREEN: two prompt versions, a context-policy component, no-op-on-unchanged, revert restores v1 exactly,
history append-only, manifest stable.
