## What it is
A 2026 survey that examines LLM agents through a **model-harness lens** — an agent is a foundation model
coupled with an execution harness. Its central question: **where is the bottleneck — the model, the
harness, or the coupling between them?** Its answer is a framing this project already holds: *"agent
quality — success, efficiency, safety, generalization — emerges from the interaction between model
capability, runtime infrastructure, task structure, and evaluation design."*
