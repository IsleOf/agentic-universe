  measure the actual per-step `p` and handoff shed rate — a real multi-agent harness. **No degraded
  mode** (a text model guessing "did that step succeed" reintroduces the assumption). **Cheap half-step:**
  a single-agent run with Phase 0 instrumentation to fit `p` from STEP outcomes, plugged into the
  existing sim.
