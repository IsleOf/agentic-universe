## The finding
The redundancy assumption behind an authorization quorum — N independent
reviewers give N-fold safety — is usually false. Distinct reviewers "often share
upstream telemetry, documents, or tool backends", so one corrupted source fails
many votes at once.

- Model reviewers + their inputs as a causal DAG. For each fault root `c`, the
  exposure map `D(c)` is the set of reviewers structurally reachable from `c`.
  Overlapping exposure sets are **epistemic fault domains**.
- The **Structural Epistemic Cut `κ_E`** = the minimum number of fault roots
  whose exposure covers a minimal decisive coalition. **`κ_E`, not `|Q|`, is the
  resilience number.**

**Empirical** (120-task benchmark, 5 operational domains, 3 evidence packages per
task, `E₁` corrupted on unsafe tasks):

| config | structure | `κ_E` | unsafe commits (2-of-3) |
|---|---|---|---|
| Q1 | same model + evidence | 1 | 97.3% |
| Q2 | different models, **shared evidence** | 1 | 96.8% |
| Q3 | same model, **separated evidence** | 2 | 6.7% |
| Q4 | diverse models + paths | 2 | 6.7% |

- Path separation alone: **14.5×** improvement. Unanimity on separated paths:
  **670×** (0.11% failure).
- Common-cause activation: a shared-telemetry fault took quorum failure from
  **0.4% → 99.6%**.
- **Scaling paradox:** 1 → 7 reviewers with shared evidence held ~96–100% unsafe
  commits. Adding voters without addressing dependencies cannot help.

**Mitigation — DAQC:** admit a COMMIT vote iff `|Q| ≥ q_min AND κ̂_E ≥ k_min`,
where `κ̂_E` is recomputed at runtime from captured evidence lineage. A failing
vote is denied and forced to full reconfiguration.

## Why it lands here
- `gates.g4_release` (quorum-not-veto, `min_quorum=2`) counts prior **passes**
  but has **no model of whether those validators read the same thing**. Every
  agent reads the same pheromone board and the same task ledger — structurally
  this is **Q2 (`κ_E=1`)**.
- Run 417's `quorum_homogeneous` flag (≥3 passes, identical confidence to 2dp, no
  distinct reasons) is a **symptomatic** detector — it catches correlation in the
  **outputs**. `κ_E` is the **structural** version: check the inputs' provenance
  before counting the vote. To reach `κ_E ≥ 2` the substrate would need
  per-validator evidence-lineage capture and a G4 line that denies release when
  all counted passes share an evidence domain.
- **Second independent reason not to lean on quorum:** run 428 showed a vote
  synthesis is *budget*-negative; this shows a shared-evidence quorum is
  *safety*-negative.
- Small-model relevance: the effect is structural (shared inputs), size-
  independent — and a fleet of identical small local models is *more* prone to
  `κ_E=1` because model diversity is also absent.
