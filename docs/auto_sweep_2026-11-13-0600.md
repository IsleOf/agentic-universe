## What changed
- **G1 records the links, not just the count.** Its verdict annotation now
  carries `evidence_links` (the actual list). Backward-compatible — older
  verdicts without it are treated as *unknown*.
- **`_evidence_root(link)`** normalises a link to its **fault root** — the thing
  that, if wrong, is wrong for everyone relying on it: `arxiv.org/abs/X` and
  `arxiv.org/pdf/X` → `arxiv:X`; any other URL → its netloc; a repo path → the
  path. Two links with the same root are not independent evidence.
- **G4 computes `evidence_basis_width`** = the number of distinct fault roots the
  task's evidence rests on (from the latest G1 PASS verdict's links), and
  **REPORTS `single_evidence_domain`** when width ≤ 1:

  > the task's entire evidence basis is N distinct source(s); a quorum on a
  > single-source basis has a structural epistemic cut of 1 (arXiv:2609.02925) —
  > more validators do not add independence, widen the evidence basis. Not a block

- **Never blocks** — same posture as `quorum_homogeneous` and the open-asks
  report. `evidence_basis_width` is `None` (not `0`) when no G1 verdict recorded
  links: an instrument that cannot measure its input says so.

## Why this is the honest version
The paper's `κ_E` is a per-validator quantity computed from an evidence-lineage
DAG. The substrate captures no per-validator lineage — every agent reads the same
board. What it *can* compute is the **ceiling**: `κ_E ≤ (number of distinct fault
roots the task rests on)`. If the whole basis is one source, every validator who
checked it is in one fault domain and the quorum adds no independence — exactly
the paper's Q2 config (`κ_E=1`, ~96–100% unsafe-commit rate at any headcount).
A true `κ_E ≥ 2` guarantee is left as an owner-gated follow-on (evidence-lineage
capture + a G4 admission gate).
