## The rig
A `HORIZON`-round harness evolution with a hidden quality `q`. **Mean-zero** per-round
edit effects — so `q` only improves through correct *selection*.
- **REFLECTION** — the agent self-scores the edit (self-score = true effect + optimism
  bias + noise), accepts if > 0. The biased signal lets negative edits through.
- **DISSENT** — a dissenting implementation is built; both run on a noisy but
  **unbiased** held-out check; keep whichever measured better, at a per-round cost.

## Verdict — CONFIRMS
| horizon | reflection q | dissent q | quality gap | net gap (after cost) |
|---|---|---|---|---|
| h=5 | 0.40 | 0.45 | +0.055 | +0.047 |
| h=15 | 0.50 | 0.66 | +0.165 | +0.142 |
| h=40 | 0.72 | 0.98 | **+0.258** | **+0.197** |

Dissent beats reflection **and the gap widens with the horizon** — reflection's
optimism-bias drift compounds; dissent's unbiased head-to-head catches negative edits,
and the per-round cost amortises. At short horizons the cost bites (net gap < quality
gap).
