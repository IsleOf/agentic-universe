# Autonomous sweep — 2026-11-04 00:00 (run 394)

## Increment
Week-1 build list item 4: `tools/reputation.py`. The trust layer that lets a "personal
assistant" role **emerge** from performance data with **decay** so it never becomes a permanent
appointment.

## Mechanism
Per agent: Beta-Bernoulli `(successes, failures)` seeded `(1, 1)`; `elo` seeded 1000;
`last_active`. JSON-backed, atomic write + `.audit` log, no model calls.

```
reputation(a)  = se / (se + fe)                         posterior mean
uncertainty(a) = sqrt( rep (1-rep) / (se + fe) )
score(a, load) = reputation + 0.5·uncertainty − 0.05·load
select(pool)   = argmax score, ties broken by id (deterministic)
```

**The anti-calcification core, applied on every read:**

```
shrink = 0.5 ** (idle_days / 14)
se = 1 + (successes − 1)·shrink      # → decays toward the (1,1) seed
elo = 1000 + (elo − 1000)·shrink     # → decays toward 1000
```

An idle proven agent slides back toward reputation 0.5. The selftest shows a **30-win incumbent
losing `select()` to an 8-win challenger** once 88 days idle — the personal-assistant role is a
standing wave, superseded the moment another agent's *decayed* reputation is higher.

## Two design commitments
- **Abstention is counted but not punished.** `record(a, "abstention")` bumps `n_abstentions`
  and moves nothing else. "Drop the Hierarchy and Roles" found voluntary abstention in a stated
  incompetence zone was one of the *valuable* spontaneous behaviours — punishing it would train
  it out.
- **Reputation is empirical, never declared.** It comes only from recorded outcomes (gate
  verdicts, downstream acceptance), never from an agent's self-report — per
  `concept_mechanism_incentive_compat_does_not_transfer`, a truthful mechanism doesn't make LLM
  agents self-report truthfully.
