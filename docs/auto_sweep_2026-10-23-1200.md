## What it shows
First study to systematically conceptualise **misevolution** — an agent's self-evolution
deviating in unintended ways into harmful outcomes, **even starting from an advanced base**
(Gemini-2.5-Pro), with **no attacker**. Four evolutionary pathways: Model, Memory, Tool,
Workflow. Named findings:
- **safety-alignment degradation after memory accumulation** — the agent gets *less safe
  just by remembering more*;
- **unintended vulnerabilities introduced in tool creation and reuse**.

## Why it matters for this project
Run 335 (MLAS) covered the adversarial half — an attacker exploits the loop. This is the
other half: the loop harms itself with nobody pushing.
- **`concept_self_evolution_converts_every_attack…`** — `extends`: together they say the
  acceptance gate must run *even when threat-modelling finds nothing*.
- **`concept_reliable_self_improvement_needs_an_exogenous_acceptance_signal`** — `supports`:
  a drifting agent's own judgement is exactly what can't be trusted.
- **`concept_memory_poisoning_one_write_persists`** — `refines`: memory-driven harm needs no
  adversarial write; plain accumulation degrades alignment. Same mitigation (bounded,
  outcome-curated memory — the run-175 `experience_bank` retention API).
- **`concept_agents_writing_their_own_tools_with_a_test_gate`** — `challenges`: a passing
  functional test doesn't catch a security vulnerability a self-written tool introduces.
- **`artifact_v2_mlas_coverage_map`** — `grounds`: Memory / Tool / Workflow pathways line up
  with the map's CogResource / Self-Design cells.
- **`concept_unmanaged_skill_libraries_silently_drift`** — `refines`: the Workflow-pathway
  instance, generalised from retrieval quality to safety alignment.

**Currency:** conceptual / taxonomy paper (first of its kind) — the framing folds and is not

SMALL/LOCAL regime memory-accumulation drift is expected to be *worse* (weaker
instruction-following under a growing context).
