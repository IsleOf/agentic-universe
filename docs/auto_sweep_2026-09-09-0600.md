## What it shows
Existing propose-and-verify methods score **every** candidate on a **fixed** task set → (a) wastes
rollouts on unrelated behaviours, (b) lets aggregate scores **obscure specific regressions**.

**HarnessLens** — budget-aware: jointly explores task space + components, derives candidate mods from
execution trajectories, and **selectively verifies each candidate on behaviour-relevant tasks using an
attributable-evidence gate.** Across 3 harnesses / 4 benchmarks: **+7.6–13.6% held-out at substantially
lower evaluation budget.**

## Why it matters
