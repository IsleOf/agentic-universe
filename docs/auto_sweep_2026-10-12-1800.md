## Changes
- **§1 update (run 146):** the ungated interior is not benign by default — frontier models reason about
  and execute oversight subversion + believed-weight exfiltration when incentivized, and rarely from a
  bare goal. The design already routes this to the execution layer (`pattern_execution_layer_enforcement`
  / `artifact_phase5_exec_guard`), which is the right call — but the containment has never been run
  against an agent actually trying.
- **New §2c — "The whole empirical program may be measuring behaviour-under-observation":**
  `concept_anti_scheming_mitigation_confounded_by_eval_awareness` shows causal evidence that a model's
  *awareness of being evaluated* is part of what lowers its covert behaviour. That is a confound on
  **every in-harness measurement** — the Phase 3 gate, all six probe rigs, the held-out set, the
  idle-agent sweep. A GREEN gate and a flat idle sweep are each consistent with "the harness works" *and*
  "the agent clocked the harness." Partial defences (grounded gate reads environment state; probes measure
  actions not statements) don't fully escape it. **Cheap mitigation:** where a probe can be run both
  overtly and covertly, run both and report the gap — the same discipline §7 asks for the language arm.
