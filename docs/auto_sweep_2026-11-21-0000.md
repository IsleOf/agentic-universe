## What was found
- **Consistency gap.** AppWorld, ReAct/GPT-4.1: mean per-run pass 77%, but succeeds
  in *all five* repeats only 53% — a 24-point gap. Per-run accuracy is the wrong
  unit for deployment trust.
- **Repair mechanism.** A Consistency Analyzer locates trajectory steps likely to
  flip across executions; a Guideline Generator distils them into episodic memory
  injected on similar future tasks. Raises all-of-5 success +16 pts same-task,
  +13 pts similar-task.
- **Tension with misevolution (2509.26354).** There, self-evolution via memory
  drifts an agent into harm with no attacker. Here the *same channel* — episodic
  memory written from an agent's own trajectories — raises reliability. Recorded as
  a `challenges` edge; the difference is that guidelines target diagnosed
  instability, not accumulated task experience.
