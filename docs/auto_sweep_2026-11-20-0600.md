## What it does
- **`build_graph(trace)`** — reads MESSAGE events (`sender` / `receiver` are on
  every one, `pattern_five_w_message_instrumentation`), normalises ids
  (strip + casefold, matching `pheromone._norm_agent`), returns the directed
  multigraph: nodes, weighted edges, per-node in/out degree, message count.
- **`structural_flags(graph)`** — four flags a reader should weigh:
  - **hub** — one node appears in > 75% of all messages (a pure star centre is at
    1.0). A single point of control/failure — and an orchestrator smell the
    substrate is meant to avoid.
  - **clique** — ≥ 3 agents all mutually connected (brute-force triangles; agent
    counts are small). FGLGuard's target shape.
  - **receive_only** — a node that only ever receives. A monitor, or an agent
    talked at but not heard.
  - **no_reciprocity** — > 60% of directed edges have no return edge (≥ 3 edges).
    A hierarchy signal.

## An honest limitation
The autonomous research **loop is single-agent** (researcher only), so its own
traces have **zero MESSAGE events** and a trivial topology. This tool is for the
**swarm-layer** traces — the probe rigs, `swarm_demo`, `harness_demo` — which are
currently generated in-memory during selftests and **not persisted**. So there is
no stored swarm trace to demo it on yet; the schema path is proven by the selftest
(star → hub; mesh → clique + no hub; chain + listener → receive_only +
no_reciprocity).
