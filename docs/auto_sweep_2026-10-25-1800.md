## What it shows
Augments a pretrained LLM with self-generated task creation, knowledge accumulation, and
extensive environmental interaction in an open-ended framework — asking whether an agent can
be "an entity in its own right… reason toward broader, more ambiguous goals."
- **Demonstrated:** multi-step instruction following; cross-run information storage and reuse;
  self-proposed task generation and solving.
- **Limitations:** sensitivity to prompt design; **repetitive task-generation patterns**;
  **inability to form self-representations**.

## Why it matters
This is the closest published thing to the **idle-agent probe** (`probe_idle_agent`, the #1
severity item testing `concept_habitat_slack`). The raw capability (self-tasking + memory
accumulation) is there, but the *quality* of autonomous behaviour is poor — repetition, no
self-model. That's a concrete prediction the probe should model and a `--live` run should
measure: an idle agent with slack *will* do things, but degenerately.

- **`artifact_probe_idle_agent_rig`** — `informs`: model these failure modes.
- **`concept_autotelic_agency`** — `refines`: present in mechanism, weak in quality.
- **`concept_habitat_slack`** — `grounds`: partial empirical answer — yes, an agent with
  slack self-directs into activity, repetitively.
- **`concept_curriculum_generation_not_intrinsic_drive`** — `supports`: repetitive
  self-generation is exactly what "self-generation without a curiosity signal loops"
  predicts.
- **`emergent_spontaneous_self_inquiry`** — `challenges`: no self-representations = direct
  counter-evidence to spontaneous self-referential inquiry when idle.

**Currency:** 2025-10, GPT-4-class base; the capability ceiling is "possibly superseded", the
repetition + no-self-model failure modes are the kind that persist and are worse in the
