## Change

Self-governance (`pattern_ostrom_swarm_governance`, `emergent_whistleblowing`) **cannot wait for an agent to voice an objection** — agents publicly conform at 64–94% while privately opposing, and a lone dissenter fails to cascade in >74% of populations. Three channels that surface disagreement without requiring a public break from consensus:

1. **Anonymous flagging** — report a concern without attribution
2. **Private-channel audit** — a monitor reads same-parent-ID direct messages, where objections appear before broadcast
3. **Activation probe** — read the private disagreement directly

The design's principle here: governance has to make objection *legible*, the same way run 14's whistleblowers acted because the cheating was legible — not assume it will be spoken.
