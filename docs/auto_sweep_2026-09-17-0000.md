## Found — a hard limit on the long-running swarm

**`concept_geometric_reliability_decay`** (CANOPY `2609.01245` + `2609.01660`, VERIFIED). Multi-step task success follows a **geometric law** in a per-step reliability parameter — failures compound exponentially. **Frontier models collapse from near-perfect to near-zero within 16 steps on genuine agentic tasks** (9 models, 10,664 trajectories). APIFlow-Bench: 93%→74% on 20-step chains, 77% of failures reach the right final state but fail at delivery.

**`concept_step_count_is_the_horizon_limit`** (`2609.01660`, VERIFIED). Degradation is driven by **step count, not context length** — and **bounding the context window steepens the decay** (logit slope −0.69 vs −0.44, p=3×10⁻⁶), contradicting lost-in-the-middle. `challenges` `concept_context_economics` and `pattern_code_as_context` *as long-horizon answers* — token management is still right about cost, wrong as the horizon fix, and context bounding can backfire.

**`pattern_deterministic_state_folding`** — the answer that works. On a 120-link task, full-context succeeds 8/30; folding each step into an explicit deterministic running state succeeds **30/30** (Live Trace Model). SKILL.state: explicit mutable state recovers accuracy *and* cuts tokens. The context the agent sees is a rendered view of a state machine the harness maintains, not a transcript.

The two findings push hard toward one design: **short agents + four-field constraints + explicit deterministic state**.
