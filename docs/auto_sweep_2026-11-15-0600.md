`no_alternative_hypothesis` flag — a clean A/B in the selftest.

the G4 validator, since relay handoff markers make prior-stage agents contributors
to the final task). The happy-path test moved 3 → 4 agents. This is the same
"gated work needs enough agents" floor as the existing k=2 limit — recorded, not
hidden.
