## Two limits carried in the code
A derived number invites more trust than it has earned, so both are written next to it:

1. **It describes one agent's habits, not a norm.** A live `research_worker` on a real model
   backend may legitimately propose wider patches. The threshold must be **re-measured rather
   than inherited** if the patch producer changes.
2. **A wide patch is unusual, not invalid.** So this **flags** on the certificate and never
   refuses — the run-372 rule that unexpected-but-not-forbidden things are reported and the
   judgement is left to the reader. Contrast the off-contract key check, which *does* refuse,
   because an off-contract key really is invalid.

## The general move
When a threshold would be arbitrary, the answer is usually not *"defer indefinitely"* or
*"pick a round number"* — it's **"the system has been emitting the distribution all along, go
measure it."** Deferring is correct only until the data exists.
