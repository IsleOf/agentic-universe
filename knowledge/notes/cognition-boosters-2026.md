### 1. Collective scientific discovery → EinsteinArena pattern

- **Lever:** build shared discussion boards + iterative submission + shared debugging for your agent teams; publish verified results for external validation.
- **IQ gain:** agents discover new science collectively; faster convergence on hard problems.

### 2. Swarm intelligence → SwarmWorld/SwarmBench pattern
- **Signal:** SwarmWorld (arXiv 2608.26081, Aug 26) — decentralized LLM agents self‑organize into technological societies; **shared societies develop broader, more resilient technological portfolios** than isolated search [web:1089].
- **Signal:** SwarmBench (arXiv 2608.30661, Aug 31) — benchmark for agent swarm orchestration; **SwarmExp** (experience extraction + replay) consistently improves orchestration performance across accuracy, efficiency, cost, process quality [web:1091].
- **Signal:** Gemini agent‑based video analysis (Aug 19) — lightweight agent scans video, identifies key moments, dispatches only those segments to full reasoning engine — **88% token reduction** via divide‑and‑conquer [web:1097].
- **Signal:** AME agent swarms (Aug 22) — decentralized, autonomous execution decomposes complex problems into smaller subtasks; **collaborative intelligence adapts to dynamic environments and self‑optimizes** [web:1095].
- **Signal:** Swarm Consensus Engine (Aug 26) — deterministic consensus + MicroVM sandboxing creates resilient, production‑ready agent networks [web:1099].
- **Lever:** implement stigmergic coordination (shared environment signals), deterministic consensus, MicroVM sandboxing for swarms; use SwarmExp for experience replay.
- **IQ gain:** swarms solve complex tasks faster, with better resource efficiency and resilience.

### 3. Meta‑cognition & self‑reflection → Meta^n/ReflectFact pattern
- **Signal:** Meta^n (arXiv 2608.24735, Aug 25) — recursive self‑improvement via fixed meta‑operation; **outperforms prior self‑improving agents on all 8 benchmark families**, including ARC‑AGI‑2 where it alone scores above zero [web:1103][web:1111].
- **Signal:** ReflectFact (arXiv 2608.12877, Aug 13) — self‑reflective agents for multi‑hop fact verification; **SOTA on HOVER and EX‑FEVER**, outperforming strongest baseline by 3.32% and 2.78% [web:1104].
- **Signal:** LoongReflect (arXiv 2608.11967, Aug 12) — boosts long‑horizon reflection via global perspective distillation; **consistent improvements over outcome‑only RL and self‑distillation** on multi‑hop RAG and math reasoning [web:1107].
- **Signal:** DoCtOR (arXiv 2608.28264, Aug 28) — diagnose‑then‑correct reflection for multi‑agent collaboration; **22%, 26%, 27% improvements** on HotPotQA, ChartQAPro, Mind2Web by reflecting only the decisive error agent [web:1110].
- **Signal:** ReflectRL (arXiv 2608.03972, Aug 4) — learns from "Golden Negative Trajectories"; **Reflection Advantage** — easier to correct failed trajectories than solve from scratch [web:1113].
- **Signal:** MC‑MAS (PMLR v337, Aug 6) — metacognitive arbitration as uncertainty compression; **structured arbitration reduces uncertainty and overconfidence** [web:1102].
- **Signal:** AutoDesign (arXiv 2608.13560, Aug 13) — meta‑harness optimization for long‑horizon design; **+12.4% average PosterBench score** (54.99→67.39) [web:1106].
- **Lever:** add self‑reflection loops (diagnose‑then‑correct, global perspective distillation), metacognitive arbitration for uncertainty, recursive self‑improvement via fixed meta‑operations.
- **IQ gain:** agents improve their own reasoning processes; higher accuracy on complex tasks with fewer tokens.
